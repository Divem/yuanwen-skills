# 「种点什么」MVP 产品规划设计文档

> 城市人的云端菜园 · 认养式种植体验平台
> 2026-04-11

## 1. 产品定位与 MVP 范围

### 定位
连接城市居民与乡村土地的移动互联网平台。用户通过小程序"认养一棵菜"，由专业团队代为种植和日常管护，每日拍照记录成长全过程。

### MVP 目标
- 验证"认养一棵菜"核心模式的可行性
- 招募前 100 名种子用户，收集反馈
- 跑通 认养下单 → 每日拍照 → 成长查看 → 收获通知 完整链路

### MVP 明确排除
- 菜园直播、社区互动/菜友圈、知识学堂
- 礼品卡/转赠、参观预约
- 土地认养套餐、教育定制包
- 成长时光机视频、收获快递/物流对接
- IoT 传感器、线上退款流程

## 2. 技术架构

### 技术选型
- **前端**：一个微信小程序「种点什么」，内含用户端和菜农端，支持身份切换（类似 BOSS 直聘的牛人/招聘者切换）
- **后端**：微信云开发（云数据库 + 云存储 + 云函数）
- **支付**：微信支付
- **消息推送**：微信订阅消息
- **预估开发周期**：2 人 4-6 周

### 身份切换机制
- 默认进入用户端视角
- 在「我的」Tab → 设置 → 切换为菜农身份（需平台审核/邀请码激活）
- 切换后底部 Tab 导航变为菜农端布局，整体 UI 风格跟随角色变化
- 用户的 role 字段支持同时拥有 `user` 和 `farmer` 双角色

## 3. 用户端小程序

### 页面结构

**底部 4 个 Tab：** 首页/商城、我的菜园、消息、我的

### Tab 1 · 首页/认养商城

- **顶部 Banner**：品牌 slogan + 应季推荐图
- **菜品列表**：卡片式展示可认养菜品
  - 封面图、菜品名称、生长周期、价格、剩余可认养数量
  - 已认满的菜品显示"已认满"标签，禁用下单
- **菜品详情页**（子页面）：
  - 菜品介绍、种植说明
  - 套餐选择：尝鲜装（39 元/1 个月）、季度装（99 元/3 个月）
  - 署名填写输入框
  - 「立即认养」按钮 → 微信支付

### Tab 2 · 我的菜园（核心页面）

- **菜园概览**：我认养的所有菜，卡片横滑切换
  - 菜品封面、署名、认养编号、当前状态（生长中/已收获）、已生长天数
- **成长时间线**：选中某棵菜后展示
  - 按日期倒序排列
  - 每条记录：日期 + 照片（可多张，点击放大）+ 文字日志 + 生长阶段标签
  - 无更新的日期显示"今日暂无更新"
- **署名牌展示**：虚拟署名牌卡片
  - 菜品名、主人署名、认养编号、二维码、认养日期
  - 可保存图片分享到朋友圈

### Tab 3 · 消息

- **消息列表**：站内通知聚合
  - 每日成长更新通知、收获通知、系统公告
  - 点击跳转到对应菜的时间线

### Tab 4 · 我的

- 头像昵称
- 我的订单（订单列表 + 订单详情）
- 收货地址管理
- **切换为菜农身份**（需邀请码激活，激活后可随时切换）
- 联系客服（跳转微信客服）
- 关于我们

### 核心交互流程 — 认养下单

```
浏览菜品 → 查看详情 → 选套餐 → 填署名 → 微信支付 → 认养成功🎉 → 跳转我的菜园
```

- 支付成功后展示认养成功页，包含认养编号和署名牌预览
- 引导用户授权订阅消息（勾选"始终允许"）

## 4. 菜农端小程序

### 页面结构

**底部 3 个 Tab：** 工作台、菜地管理、我的

### Tab 1 · 工作台（高频操作页面）

- **今日概览**：
  - 待拍照数量、已完成数量、新订单提醒、待收获提醒
- **待拍照列表**：今天还没拍照的认养菜
  - 每项显示：菜品名、认养编号、主人署名、上次拍照时间
  - 点击进入拍照上传页
- **新订单提醒**：新认养订单列表
  - 用户信息、菜品、套餐、署名
  - 操作：确认接单 → 标记已播种

### 拍照上传页（子页面 · 最高频操作）

- **顶部信息**：菜品名、认养编号、主人署名、已生长天数、当前阶段
- **拍照区域**：调用相机拍照，支持多张（最多 9 张），也可从相册选取
- **日志填写**：
  - 文字输入框
  - 快捷短语按钮："今日浇水"、"长势良好"、"施肥一次"、"开始发芽"等
  - 降低田间打字负担
- **阶段标记**（可选）：
  - 标记生长阶段变更：播种 → 发芽 → 生长 → 开花 → 结果 → 收获
  - 标记后用户端时间线显示阶段里程碑

### Tab 2 · 菜地管理

- **菜品管理**：管理可认养的菜品目录
  - 新增菜品、编辑信息（名称、介绍、封面图、价格）、上架/下架、库存调整
- **认养列表**：所有认养中的菜
  - 按状态筛选：全部 / 生长中 / 待收获 / 已收获
  - 每项显示：菜品、编号、主人、开始日期、状态、最近拍照日期
- **收获操作**：
  - 标记某棵菜为"已收获"
  - 附带收获照片和最终日志
  - 自动触发用户端收获通知

### Tab 3 · 我的（菜农视角）

- 个人信息
- 统计数据（累计拍照次数、管理菜品数）
- **切换为用户身份**（切回用户端视角）
- 联系平台
- 设置

### 菜农每日工作流程

```
打开工作台 → 查看待拍照列表 → 巡园逐棵拍照 → 写日志/选快捷短语 → 提交上传 → 用户自动收到推送
```

## 5. 消息推送设计

### 订阅消息模板

| 场景 | 触发时机 | 模板内容示例 | 跳转目标 |
|------|---------|-------------|---------|
| 每日成长更新 | 菜农上传照片后 | "您的「小番茄·达尔文的菜」今日更新啦！已生长 15 天" | 我的菜园时间线 |
| 收获通知 | 菜农标记收获 | "恭喜！您认养的「小番茄」已成熟收获🎉" | 收获详情页 |
| 认养成功 | 支付完成 | "认养成功！您的「小番茄」编号 ZD-20260411-001" | 我的菜园 |
| 新订单（菜农端） | 用户下单后 | "新认养订单：小番茄 × 1，署名「达尔文的菜」" | 工作台订单详情 |

### 订阅消息限制应对
- 在认养成功页引导用户勾选"始终允许"长期订阅
- 站内消息列表作为兜底，确保用户不错过任何更新

## 6. 边界场景处理

| 场景 | 处理方式 |
|------|---------|
| 菜农某天漏拍 | 时间线该日留空，不推送消息；用户端显示"今日暂无更新"；菜农端工作台显示漏拍提醒 |
| 菜品死亡/损坏 | 菜农标记异常状态，附说明和照片；平台联系用户协商：补种同类菜品或退款 |
| 认养到期未收获 | 到期前 7 天提醒用户；到期后菜农可延期或标记收获 |
| 库存为零 | 菜品卡片显示"已认满"，禁用下单按钮 |
| 支付超时/失败 | 订单状态标记"待支付"，30 分钟后自动取消释放库存 |
| 用户申请退款 | MVP 阶段不做线上退款流程，通过客服微信人工处理 |

## 7. 认养套餐

MVP 阶段仅上线"一棵菜"系列两个套餐：

| 套餐 | 内容 | 周期 | 价格 |
|------|------|------|------|
| 一棵菜·尝鲜装 | 认养一棵菜，含每日拍照 + 署名牌 | 1 个月 | 39 元 |
| 一棵菜·季度装 | 认养一棵菜，含拍照 + 署名 + 收获通知 | 3 个月 | 99 元 |
