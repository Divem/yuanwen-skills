## 二、微信小程序注册指南

### 2.1 注册前准备

#### 主体资质要求
| 主体类型 | 所需材料 |
|---------|---------|
| 企业 | 营业执照、对公账户、管理员身份证 |
| 个体工商户 | 营业执照、法人身份证、银行卡 |
| 个人 | 身份证（功能受限，不支持支付） |

> **建议**: 使用企业主体注册，以便开通微信支付功能

#### 账号信息准备
```
账号名称: 种点什么
账号类型: 小程序
服务类目: 电商平台 / 农业服务
```

### 2.2 注册流程

#### 步骤 1: 注册小程序账号
1. 访问 [微信公众平台](https://mp.weixin.qq.com/)
2. 点击右上角「立即注册」
3. 选择「小程序」
4. 填写邮箱（未注册过微信公众平台的邮箱）
5. 查收邮件激活账号
6. 选择主体类型（推荐：企业）
7. 填写主体信息并认证

#### 步骤 2: 微信认证（企业主体）
- 认证费用：300 元/年
- 认证时间：1-5 个工作日
- 支付方式：对公转账或微信扫码

#### 步骤 3: 完善小程序信息
| 配置项 | 内容 |
|-------|------|
| 小程序名称 | 种点什么 |
| 小程序简称 | 种点 |
| 头像 | 上传 logo.png |
| 介绍 | 城市人的云端菜园，认养一棵菜，收获一份鲜。每日拍照记录成长，体验种植的乐趣。 |
| 服务类目 | 电商平台 > 自营电商 |
| 标签 | 认养,种植,菜园,有机蔬菜,城市农场 |

### 2.3 支付能力开通

#### 微信支付商户申请
1. 登录小程序后台 → 微信支付 → 开通
2. 选择「申请接入」
3. 填写商户信息：
   - 商户简称：种点什么
   - 经营类目：实物电商 / 农产品销售
   - 公司网站：可填公众号或官网（如有）
4. 提交审核（1-3 个工作日）

#### 费率信息
| 交易类型 | 费率 |
|---------|------|
| 小程序支付 | 0.6% |
| 企业付款到零钱 | 按金额收费 |

### 2.4 开发配置

#### 服务器域名配置
```
request 合法域名:
  - https://api.weixin.qq.com
  - https://api.mch.weixin.qq.com
  - 你的云开发域名

socket 合法域名: （无需配置）

uploadFile 合法域名:
  - 你的云存储域名

downloadFile 合法域名:
  - 你的云存储域名
```

#### 云开发配置
1. 小程序后台 → 云开发 → 开通
2. 选择「按量付费」或「包年包月」
3. 记录环境 ID
4. 配置数据库权限

### 2.5 订阅消息配置

#### 申请消息模板
登录小程序后台 → 功能 → 订阅消息 → 添加模板

| 模板类型 | 用途 |
|---------|------|
| 每日成长更新 | 菜农上传照片后推送给用户 |
| 收获通知 | 菜品收获时推送 |
| 认养成功通知 | 支付完成后推送 |
| 新订单提醒 | 用户下单后推送给菜农 |

#### 模板关键词示例（每日成长更新）
```
{{thing1.DATA}} - 菜品名称
{{thing2.DATA}} - 生长天数
{{time3.DATA}} - 更新时间
{{thing4.DATA}} - 状态描述
```

## 三、App Store (iOS) 注册指南

### 3.1 开发者账号注册

#### 账号类型选择
| 类型 | 费用 | 适用 |
|------|------|------|
| 个人开发者 | $99/年 | 个人开发者 |
| 公司开发者 | $99/年 | 企业/团队 |
| 企业开发者 | $299/年 | 内部应用分发 |

> **建议**: 选择「公司开发者」，可展示公司名称

#### 注册流程
1. 访问 [Apple Developer](https://developer.apple.com/)
2. 点击「Account」→ 使用 Apple ID 登录
3. 加入 Apple Developer Program
4. 选择账户类型（Company/Organization）
5. 填写公司信息：
   - 公司法定名称
   - D-U-N-S 编号（邓白氏编码）
   - 公司网站
   - 公司电话
6. 支付年费：$99
7. 等待审核（通常 48 小时内）

#### D-U-N-S 编号申请（如没有）
1. 访问 [D-U-N-S 申请页面](https://developer.apple.com/enroll/duns-lookup/)
2. 查询是否已有编号
3. 如无，提交申请（免费）
4. 等待 5-14 个工作日
