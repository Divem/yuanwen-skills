# 基础瑜伽课程摘要

## 课程概况

- 名称：基础瑜伽入门班
- 时长：12 周，每周 2 次，每次 60 分钟
- 适合：零基础、久坐上班族、压力大的人群

## 核心目标

1. 掌握基础体式和呼吸法
2. 改善柔韧性和核心力量
3. 建立规律练习习惯

## 课程结构

1. **第一阶段（1-4 周）**：入门基础，呼吸法 + 基础体式
2. **第二阶段（5-8 周）**：体式深化，平衡 + 核心 + 扭转
3. **第三阶段（9-12 周）**：综合练习，完整序列 + 自主练习

## 课程亮点

- 小班教学（不超过 8 人）
- 个性化调整
- 课后视频 + 社群支持
