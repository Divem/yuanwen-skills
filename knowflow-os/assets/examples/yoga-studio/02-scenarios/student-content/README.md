# 学员内容运营场景

## 目标

通过小红书和朋友圈，持续输出瑜伽相关内容，吸引潜在学员，维护现有学员粘性。

## 复用知识资产

- `../../01-knowledge-base/brand/yoga-studio-brand/` → 品牌故事、核心理念
- `../../01-knowledge-base/courses/basic-yoga-course/` → 瑜伽干货、课程信息
- `../../01-knowledge-base/people/instructor-lin/` → 老师日常、专业分享
- `../../01-knowledge-base/cases/student-case-zhang/` → 学员故事（脱敏）

## 内容方向示例

1. 「久坐党必看！这 3 个瑜伽动作拯救你的腰椎」→ 复用课程知识资产
2. 「零基础学瑜伽 6 个月，我发生了这些变化」→ 复用学员案例
3. 「从互联网产品经理到瑜伽老师，我找到了自己的节奏」→ 复用老师介绍
4. 「为什么我们选择小班教学？」→ 复用品牌介绍
