# 外部品牌传播场景

## 目标

通过官网、公众号和宣传册等渠道，对外展示静心瑜伽馆的品牌形象和专业实力。

## 复用知识资产

- `../../01-knowledge-base/brand/yoga-studio-brand/` → 官网关于我们、品牌故事
- `../../01-knowledge-base/courses/basic-yoga-course/` → 课程详情页、宣传册课程板块
- `../../01-knowledge-base/people/instructor-lin/` → 团队介绍页
- `../../01-knowledge-base/cases/student-case-zhang/` → 成功案例页面（脱敏）

## 可生成内容

1. **官网文案**：首页、关于我们、课程介绍、团队介绍、联系我们
2. **品牌宣传册**：品牌故事 + 课程介绍 + 团队 + 案例
3. **媒体通稿**：品牌故事角度、创始人故事角度
