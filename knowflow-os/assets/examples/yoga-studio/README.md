# 瑜伽馆示例

本示例演示：同一份知识资产，如何被多个业务场景复用。

## 知识资产

### 品牌介绍

- 路径：`01-knowledge-base/brand/yoga-studio-brand/`
- 内容：瑜伽馆品牌定位、品牌故事、核心价值观

### 基础瑜伽课程

- 路径：`01-knowledge-base/courses/basic-yoga-course/`
- 内容：基础瑜伽课程大纲、教学目标、课程亮点

### 老师介绍

- 路径：`01-knowledge-base/people/instructor-lin/`
- 内容：林老师个人背景、教学风格、专业资质

### 学员案例

- 路径：`01-knowledge-base/cases/student-case-zhang/`
- 内容：张学员的学习经历、成长变化、反馈（已脱敏）

## 场景复用

### 学员内容运营（student-content）

生成小红书、朋友圈、社群内容。

**复用资产：**
- 品牌介绍 → 品牌故事短文
- 基础瑜伽课程 → 瑜伽干货分享
- 老师介绍 → 老师日常分享
- 学员案例 → 学员故事

### 课程与培训（course-training）

生成课程大纲、培训课件、学员手册。

**复用资产：**
- 品牌介绍 → 课程品牌页
- 基础瑜伽课程 → 完整课程大纲和课件
- 老师介绍 → 讲师介绍页
- 学员案例 → 课程效果展示

### 外部品牌传播（external-pr）

生成官网文案、媒体通稿、宣传册。

**复用资产：**
- 品牌介绍 → 官网关于我们、品牌故事
- 基础瑜伽课程 → 课程详情页
- 老师介绍 → 团队介绍页
- 学员案例 → 成功案例页面

## 工作流示例

1. **import-and-classify**：将瑜伽馆资料导入并分类到知识资产库
2. **knowledge-to-topic**：从知识资产生成选题（如「零基础如何开始瑜伽」）
3. **topic-to-content**：将选题加工成不同渠道内容
4. **content-to-publish**：准备发布内容
5. **publish-to-review**：发布后复盘
