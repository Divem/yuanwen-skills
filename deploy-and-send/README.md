# Deploy and Send

构建项目、打包为 zip、通过飞书发送。

## 功能特性

- 自动构建项目（运行 `build` 脚本）
- 将 `dist/` 目录打包为 zip
- 通过飞书机器人发送给指定用户
- 发送失败时自动降级到云盘上传

## 前置条件

- 项目根目录有 `package.json` 且包含 `build` 脚本
- lark-cli 已安装并登录（`lark-cli auth login`）
- 项目构建后生成 `dist/` 目录

## 使用方法

直接对 Claude 说：

```
"打包发送"
"部署并发送"
"发给我"
"只打包不发"
```

也可以指定参数：

```
"打包 xxx 项目发给张三"
"打包成 demo.zip"
```

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 项目目录 | 当前目录 | 要构建的项目路径 |
| zip 文件名 | `dist.zip` | 输出文件名 |
| 接收人 | 默认用户 | 飞书用户 ID（`ou_...`） |
| 仅构建 | false | 是否只打包不发送 |

## 工作流程

1. 解析用户意图，确认参数
2. 执行 `npm run build` 构建项目
3. 将 `dist/` 打包为 zip
4. 通过飞书发送文件
5. 发送失败则降级为云盘上传

## 注意事项

- `--file` 参数必须使用相对路径
- 发送失败时会自动尝试云盘上传
- 构建失败不会执行发送步骤
