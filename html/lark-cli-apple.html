快速开始

三步即可开始使用 Lark-CLI。

Step 1 — 安装
npm install -g @larksuite/lark-cli
Step 2
初始化配置
lark-cli config init
Step 3
登录授权
lark-cli auth login

认证管理

lark-cli auth login

设备流授权登录，在浏览器中完成 OAuth 授权。

lark-cli auth login --domain calendar,task
lark-cli auth status

查看当前认证状态和已授权的应用。

lark-cli auth status
lark-cli auth logout

登出并清除本地存储的 token。

lark-cli auth logout

即时通讯

lark-cli im +messages-send

发送消息到群聊或私聊。支持文本、Markdown、图片、文件等。

lark-cli im +messages-send --chat-id oc_xxx --text "Hello World"
lark-cli im +chat-messages-list

列出群聊历史消息，支持时间范围筛选。

lark-cli im +chat-messages-list --chat-id oc_xxx --format table
lark-cli im +messages-search

搜索消息历史，支持关键词和发送者筛选。

lark-cli im +messages-search --query "关键词" --sender ou_xxx

日历管理

lark-cli calendar +agenda

查看今日或指定日期范围的日程。

lark-cli calendar +agenda --format table
lark-cli calendar +create

创建日程，支持邀请参与者和设置重复规则。

lark-cli calendar +create --summary "会议" --start "2026-04-15T14:00:00+08:00" --end "2026-04-15T15:00:00+08:00"
lark-cli calendar +suggestion

智能推荐可用会议时间。

lark-cli calendar +suggestion --attendee-ids "ou_xxx,ou_yyy" --duration-minutes 60

文档操作

lark-cli docs +create

创建新文档，支持 Markdown 格式。

lark-cli docs +create --title "新文档" --markdown "# 标题\n\n内容"
lark-cli docs +fetch

通过 URL 获取文档内容。

lark-cli docs +fetch --doc "https://xxx.feishu.cn/docx/xxx"
lark-cli docs +update

更新文档内容，支持追加、覆盖或替换指定范围。

lark-cli docs +update --doc "docx_xxx" --markdown "新内容" --mode append

多维表格

lark-cli base +table-list

列出多维表格中的所有表。

lark-cli base +table-list --base-token "bascn_xxx"
lark-cli base +record-list

列出表中的记录。

lark-cli base +record-list --base-token "bascn_xxx" --table-id "tbl_xxx"
lark-cli base +record-upsert

创建或更新记录。

lark-cli base +record-upsert --base-token "bascn_xxx" --table-id "tbl_xxx" --json '{"fields":{"姓名":"张三"}}'

云盘

lark-cli drive +upload

上传文件到云盘。

lark-cli drive +upload --file /path/to/report.pdf --folder-token "fld_xxx"
lark-cli drive +download

从云盘下载文件。

lark-cli drive +download --file-token "file_xxx" --output ./downloaded.pdf

任务管理

lark-cli task +create

创建任务，支持设置截止日期和分配人。

lark-cli task +create --summary "完成文档" --due "2026-04-20" --assignee "ou_xxx"
lark-cli task +get-my-tasks

查看我的任务列表。

lark-cli task +get-my-tasks --format table
lark-cli task +complete

完成任务。

lark-cli task +complete --task-id "task_xxx"
