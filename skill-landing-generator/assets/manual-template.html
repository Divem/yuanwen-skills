feishu-sync 使用手册

本地目录与飞书云文档的双向同步工具。支持 init / push / pull / status 四种操作，覆盖从首次建立映射到日常增量同步的全流程。

版本 1.0 更新于 2026-05 作者 wen.yuan 来自 GitHub

概述

feishu-sync 是一个基于 lark-cli 的双向同步工具，用于在本地文件目录与飞书云文档之间建立映射关系并保持内容同步。

它通过 SHA256 哈希检测本地文件变更，通过飞书元数据修改时间检测远端变更，实现增量同步，避免不必要的 API 调用。

i
核心设计：.md 文件走飞书文档 API（支持富文本编辑），其他文件走云盘文件上传/下载。映射关系存储在 .feishu-sync.json 中。

前置条件

使用 feishu-sync 前需确保以下条件满足：

条件检查方式修复方式
lark-cli 已安装并认证 lark-cli doctor 安装 lark-cli 并完成登录认证
drive:drive scope 已授权 lark-cli auth check --scope drive:drive lark-cli auth login --scope drive:drive
Python 3 已安装 python3 --version 安装 Python 3
验证前置条件
# 检查 lark-cli 状态
$ lark-cli doctor
✔ 全部检查通过

# 确认 drive scope
$ lark-cli auth check --scope drive:drive
✔ scope 已授权

快速开始

三步完成首次同步：

终端
# 1. 初始化：建立映射并上传
$ /feishu-sync init --dir docs --folder https://xxx.feishu.cn/drive/folder/TOKEN

# 2. 查看同步状态
$ /feishu-sync status --dir docs

# 3. 推送本地变更
$ /feishu-sync push --dir docs

init — 首次初始化

扫描本地目录，在飞书创建对应的文件夹结构，上传所有文件，生成映射文件 .feishu-sync.json。

命令
$ /feishu-sync init --dir <本地目录> --folder <飞书URL或token>

参数说明

参数必填默认值说明
--dir否docs要同步的本地目录路径
--folder是—飞书文件夹 URL 或纯 token

执行流程

步骤操作
1扫描本地目录，收集所有文件和子目录
2在飞书创建对应的文件夹结构
3逐个上传文件（.md → 文档，其他 → 云盘文件）
4生成 .feishu-sync.json 映射文件
✓
建议：飞书侧使用空文件夹进行初始化，避免文件名冲突。--folder 支持完整 URL（https://xxx.feishu.cn/drive/folder/TOKEN）或纯 token。

push — 推送本地变更

检测本地文件哈希变化，增量创建或更新飞书文档。

命令
$ /feishu-sync push --dir <本地目录>

处理规则

本地状态操作
新文件创建飞书文档（.md）或上传云盘文件
修改的文件更新飞书文档内容（overwrite 模式）
新目录自动创建飞书文件夹
本地已删除列出提示，不自动删除飞书侧
!
注意：本地删除的文件不会自动从飞书删除，仅提示。这是有意设计，防止误删飞书文档。

pull — 拉取飞书变更

批量查询飞书元数据修改时间，拉取变更文件到本地。

命令
$ /feishu-sync pull --dir <本地目录>

工作原理

步骤说明
批量元数据查询通过 drive metas batch_query 批量检测（每批 200 个）
变更文件拉取.md 文件通过 docs +fetch 获取 Markdown；其他文件通过 drive +download 下载
新文件检测使用 docs +search 按时间过滤，检测飞书侧新建的文件

status — 查看同步状态

三向对比本地和飞书差异，输出清晰的标记符号。

命令
$ /feishu-sync status --dir <本地目录>

标记说明

标记含义建议操作
→本地改了，待 push执行 push
←飞书改了，待 pull执行 pull
⟷双边都改了（冲突）先 pull → 合并 → push
+本地新增文件执行 push
−本地已删除文件确认是否需要删除飞书侧
↓飞书新增文件执行 pull
输出示例
# 输出示例
→  README.md            本地已修改
←  api-guide.md          飞书已修改
⟷ config.md             双边都改了
+  new-feature.md        本地新增
−  old-doc.md            本地已删除

文件处理规则

feishu-sync 根据文件扩展名选择不同的同步策略：

文件类型本地格式飞书存储创建方式读取方式
.md 文件 原始 Markdown 飞书文档（富文本） docs +create docs +fetch
其他文件 原始文件 云盘文件 drive +upload drive +download
i
为什么 .md 走文档？飞书文档支持富文本在线编辑，团队成员可以直接在飞书修改内容，然后通过 pull 拉回本地。其他二进制文件（图片、PDF 等）走云盘上传下载。

冲突处理

当 status 显示 ⟷ 时，表示同一文件在本地和飞书都被修改了。

处理步骤

冲突解决流程
# 1. 先 pull 保留飞书版本
$ /feishu-sync pull

# 2. 手动合并内容
#   打开本地文件，将飞书侧的修改合并进来

# 3. 推送合并结果
$ /feishu-sync push
!
重要：pull 操作会使用飞书版本覆盖本地文件。请确保在 pull 前备份本地修改，或先手动合并。

映射文件 .feishu-sync.json

映射文件自动生成在 --dir 的父目录中，记录了本地文件与飞书文档的对应关系。

.feishu-sync.json 结构
{
  "version": "1.0",
  "folder_token": "fldcnXXXXXX",
  "local_base": "docs",
  "folder_map": {
    "sub-dir": "fldcnYYYYYY"
  },
  "files": {
    "README.md": {
      "token": "doccnZZZZZZ",
      "type": "doc",
      "local_hash": "sha256...",
      "feishu_modified": "2026-05-29T10:00:00Z"
    }
  }
}

字段说明

字段类型说明
folder_tokenstring飞书根文件夹 token
local_basestring本地同步目录名
folder_mapobject子目录名 → 飞书文件夹 token 映射
files.*.tokenstring飞书文档/文件 token
files.*.typestring"doc"（文档）或 "file"（云盘）
files.*.local_hashstring本地文件 SHA256 哈希
files.*.feishu_modifiedstring飞书最后修改时间
✓
提示：将 .feishu-sync.json 加入 .gitignore，避免映射文件被提交到版本控制。

限制与注意事项

限制说明
文件路径drive +upload 要求相对路径，不可用绝对路径
文件大小单文件限制 20MB
Markdown 格式飞书 Markdown ≠ 标准 Markdown，往返可能有格式损失
删除操作本地删除不会自动删除飞书侧文件
批量查询每批最多 200 个文件元数据
